# タスク: create_task_script

## 背景・目的

新しいタスクの開始時に必要なディレクトリと要件定義書を、一定の形式で作成できるようにする。

## 要件

- `scripts/create-task.sh` がタスク名を受け取り、`agent_docs/tasks/` 配下に日付付きのタスクディレクトリを作成する。
- タスク名を省略した場合は、対話形式で入力を受け付ける。
- 作成したディレクトリに `0000-requirements-definition.md` の雛形を配置する。
- 不正な名前や既存ディレクトリへの上書きを防ぎ、使い方を表示できる。

## 完了条件

- スクリプトが任意の作業ディレクトリから実行できる。
- 引数の検証と既存ディレクトリのエラーを明示する。
- Bash の構文検査と CLI 動作確認が成功する。
