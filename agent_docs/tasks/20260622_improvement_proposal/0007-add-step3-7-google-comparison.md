### ステップ3-7 の骨子（既存スタイル＝目的／作業内容／完了条件／注意点・リスク、ISS/TBD 紐付け、ゼロベース To-Be と漸進案の対比に準拠）

- **目的**: Google 検索サジェストを外部ベンチマークとし、「As-Is／To-Be（3-1）／Google」の三者差を考察。fess-suggest／To-Be が劣る軸の差を、3-1 のどの拡張点に載せて埋めるかを検討する。3-7 は「外部比較起点」、3-4（品質）・3-6（新機能）は「内部課題起点」という役割分担を明記。
- **前提**: Google は大規模独自データ・プロプライエタリ技術前提。fess はオンプレ／エンタープライズ・限定コーパス。前提が異なるため全模倣はしない。
- **比較軸**: プレフィックス補完／低レイテンシ、タイプミス補正・fuzzy、人気度・トレンド・鮮度、パーソナライズ、関連クエリ・ロングテール、多言語・かな/ローマ字・表記ゆれ、セマンティック／意図理解、安全性フィルタ。
- **作業内容**: 各軸で三者比較 → 劣る軸の打ち手を 3-1 の拡張点（データソース抽象・スコアリング機構・インデックス設計・テキスト処理パイプライン）への載せ方として具体化 →「埋めるべき差／fess の文脈では不要・非現実的な差」を切り分け → 既存 ISS/TBD（特に ISS-04,05,11,12,14,15）およびステップ3-4／3-6 との役割分担・重複整理（重複は再掲せず参照に留める）。
- **完了条件**: 三者差分の考察・劣る軸の特定・打ち手（または不要な差としての切り分け）・ISS/TBD と 3-4/3-6 との役割分担・TBD-01 の「要確認」引き継ぎ、を満たす。
- **注意点・リスク**: 提案・文書化でありスコープ外（実装）を維持。Google 内部実装は非公開のため外形的挙動ベースの考察にとどめる。「Google 追従」を目的化せず fess 文脈で価値ある差に絞る。移行戦略はステップ4の領分。
