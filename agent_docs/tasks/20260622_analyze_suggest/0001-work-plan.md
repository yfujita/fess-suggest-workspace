# 作業プラン: 20260622_analyze_suggest

## 概要

fess-suggest モジュール（fess のサジェスト用ライブラリ）の現状を調査し、その概要・全体アーキテクチャ・サジェストとして表示される内容を整理したドキュメントを作成する。
成果物は `agent_docs/global/references/legacy/` 配下に出力する。本プランは「分析（調査）タスク」であり、コード変更は伴わない。

## 前提・スコープ

### 対象範囲
- `modules/fess-suggest`: fess のサジェスト用ライブラリ本体の調査。
- `modules/fess`: fess 本体が fess-suggest をどのように利用しているか（呼び出し箇所・連携方法）の調査。
- 調査観点（要件定義 `0000-requirements-definition.md` より）:
  - fess-suggest の概要
  - サジェストの全体的なアーキテクチャ
  - サジェストにどのようなものが表示されるか（サジェストの種類・データソース）

### スコープ外
- コードの修正・リファクタリング・機能追加（本タスクは分析のみ）。
- 性能チューニングやバグ修正の実施（発見した課題は記録するに留める）。
- fess 本体の全機能の網羅的な調査（あくまでサジェスト連携に関わる範囲に限定）。

### 重要な前提（調査時点で確認した事項）
- 現状、`modules/fess-suggest` および `modules/fess` の **ディレクトリは空であり、ソースコードが未取得**である。
- `scripts/clone.sh` は存在するが中身が空であり、モジュール取得手順が未整備。
- `agent_docs/global/references/` は存在するが空で、`legacy/` ディレクトリは未作成。
- このため、最初に「ソースコードの取得」を解決しないと、コードベースに基づく分析が行えない。
  本プランではステップ0として取得手段の確認・準備を組み込む。

- 作業内容:
