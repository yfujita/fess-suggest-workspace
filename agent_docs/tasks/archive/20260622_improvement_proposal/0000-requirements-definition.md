# 20260622_improvement_proposal

## 要件

fess-suggestのメジャーバージョンアップ級の抜本的改善を行う。
そのための改善案を作成する。
検討は既存モジュールの構成を維持する必要はなくゼロベースで検討を行い、あるべき姿を目指す。

## 目的

- コードの可読性の向上
- コードの変更容易性の向上
- サジェスト品質の向上
- 性能面での向上
- サジェスト関連での新機能の検討

## 現在の課題感

- fess-suggestのコードが複雑になっており、保守運用や改善に高度なJavaスキルを必要としている。
- サジェストの品質が悪くはないがそこまで良いとも言えない。
- 機能的に10年以上変わっていない。
