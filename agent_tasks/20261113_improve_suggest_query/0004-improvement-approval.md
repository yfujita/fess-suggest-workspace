## 設計書に反映する論点(0003 §6 の推奨をそのまま採用)
連結語と断片の両方を候補にする / 最大連続列のみ(2 トークン以上)/ `words = { 連結語 }` の 1 語・区切りなし / 読みは構成トークンの reading をカタカナのまま連結して `contentsReadingConverter.convert` に 1 回通す / 連結後に `toLowerCase(Locale.ROOT)` / 品詞が取れない場合は連結せず従来動作 / 設定は System property(有効フラグ既定 on・最大トークン数・最大文字数)。
