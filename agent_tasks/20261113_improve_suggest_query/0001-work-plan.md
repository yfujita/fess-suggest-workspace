## 4. フェーズ

### フェーズ1: 原因調査(担当: tech-advisor。検証用スクリプトは scratchpad で実施)
H1〜H4 を検証し、原因の切り分けを確定する。
1. 文書経路・検索ログ経路それぞれで、`新型コロナ` 等がどのトークン単位で候補化されるかをコードで追跡する(アナライザ → 品詞フィルタ → 語長/頻度フィルタ → 保存)。
2. アナライザ定義の読解、または可能ならローカル/デモの API 実測で、例語が何に分割されるか、どのフィルタで落ちるかを確認する。

4. 原因を「確認 / 推測 / 要確認」で整理する。

- A: 形態素 N-gram / 連続名詞の連結を文書経路で候補化する(名詞連続を複合語として生成)。
