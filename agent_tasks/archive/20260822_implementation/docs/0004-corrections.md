## 5. タスク外への還流の申し送り（`0000` §8.1 の 7-6）

**P9（過去文書の凍結）は本設計タスク期間中の判断である。** その結果、**課題インベントリ等の「正」は提案書のまま、訂正の「正」は本書**という二重状態が残った。本タスクを知らない将来のタスクが提案書だけを読むと、E-06（KEEP-03 の無条件踏襲表記）・E-01（`MAX_READING_NUM` の誤解）などを**そのまま再継承する**。

したがって以下を**後続タスクとして起票する**ことを申し送る。**本タスクでは実施しない**（P9 の凍結期間中であり、また設計書の執筆がスコープであるため）。

| 項目 | 内容 |
| --- | --- |
| **タスクの目的** | E-01〜E-26 を提案書第 5 版および関連文書へ還流し、「正」の二重化を解消する |
| **対象文書** | `docs/improvement-proposal.md`（第 5 版）／ `20260706_opensearch_reference/0005-schema-draft.md` ／ `docs/opensearch-verification-reference.md` ／ `20260706_design_document/0003` ／ `20260706_design_document/0004` ／ `modules/fess-suggest/README.md` |
| **完了条件** | (a) 各 E 番号が対象文書に反映され、本書に「還流済み」の印が付いている。**または** (b)「還流しない」と判断した E 番号について、その理由が**提案書側に**記録されている |
| **注意** | 還流時に**提案書と本書が両方とも正になる状態を作らないこと**。還流した E 番号は本書側で「還流済み（提案書 §X.Y）」と記し、正を提案書へ移す |
| **前提** | 本設計タスクの完了（P9 の凍結解除） |

> **「還流しない」を選ぶ場合も記録が要る。** 記録が無いまま放置すると、次のタスクが本書の存在を知らずに提案書を読み、同じ誤りを再生産する。これが P9 を選んだことの代償であり、支払いを先送りにしないための申し送りである。
