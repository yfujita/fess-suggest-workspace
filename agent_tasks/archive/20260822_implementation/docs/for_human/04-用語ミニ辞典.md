## 事実か提案かのマーク

| 記号 | 意味 |
| --- | --- |
| **[事実]** / **[確認]** | ソースコード・実機・一次情報で直接確認したもの。必ず `ファイル:行番号` か URL が付いている |
| **[提案]** | 設計提案。断定ではない |
| **[確定]** | 決定済み。番号で参照する |
| **[要確認]** | 未解消。**完成した設計書には 1 件も存在しない**（実際に 0 件） |

## ドメイン用語

| 用語 | 意味 |
| --- | --- |
| **二重エイリアス** | 検索用（`fess.suggest`）と更新用（`fess.suggest.update`）の 2 つのエイリアスを使い分ける仕組み。再構築中も検索を止めずに済む |
| **保持用エイリアス（`.prev`）** | 今回新設。切り替え時に旧世代へ付けて、削除されないようにする |
| **決定的 ID** | 同じ語なら必ず同じ ID になる作り方。だから何度取り込んでも 1 つのドキュメントに集約され、頻度が足し合わさる |
| **bad word（NG ワード）** | サジェストに出したくない語。**部分一致**で判定する |
| **elevate word（優先語）** | 優先的に出したい語。`userBoost` を持つ |
| **`excluded`** | 今回追加するフラグ。NG ワードに該当する語を、消さずに隠すために使う |
| **`userBoost`** | 語ごとの重み。管理画面から設定する |
| **Kind** | 語の出所。`document` / `query` / `user` の 3 種 |
| **Strangler Fig** | 新しい実装を横に置き、古い入口をそこへ委譲させ、呼び出し元を順に移し、最後に古い方を消す移行のやり方 |
| **SPI** | Service Provider Interface。実装を差し替えるための拡張点 |
| **`refresh_interval = -1`** | OpenSearch の自動 refresh を止める設定。大量投入中の定石 |
