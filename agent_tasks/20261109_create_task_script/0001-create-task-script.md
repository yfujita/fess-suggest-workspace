# create-task.sh の作成

## 作業内容

- `scripts/create-task.sh` を追加し、タスク名から日付付きディレクトリと要件定義書の雛形を作成するようにした。
- タスク名の検証、既存ディレクトリへの上書き防止、`--help` を実装した。
- 既存の命名に合わせ、生成する要件定義書を `0000-requirements-definition.md` とした。

## 確認結果

- `bash -n scripts/create-task.sh` 成功。
- `--help` の表示、不正なタスク名の拒否、新規作成と雛形内容、既存ディレクトリの拒否を確認。
- 確認用に生成した一時ディレクトリは削除した。
