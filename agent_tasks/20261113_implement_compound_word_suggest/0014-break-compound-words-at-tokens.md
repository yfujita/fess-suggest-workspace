# 0014 特定のトークン(既定は「ら」)で連結を区切る仕組み(`fess.suggest.compound.break.tokens`)

実施: メインエージェント(原因調査・記録)、code-implementer(実装)、code-reviewer / test-reviewer(レビュー)。プランの変更ではなく、軽微な追加対応(`task-workflow.md`「途中の追加指示」)。

## 1. 原因の調査

ユーザーの問い: 語尾の「ら」(`神谷浩史ら`、`大統領ら民主党幹部`)が連結語に混じる原因は何か。

- 実環境の explain で、`ら` は **`名詞-接尾-一般`** と解析される(`神谷`/`浩史`/`ら`、`大統領`/`ら`/`民主党`/`幹部`、`研究`/`者`/`ら` など)。この品詞は `大統領選` の `選`、`円安` の `安`、`研究者` の `者`、`私たち` の `たち` と同じで、連結語を作るため連結対象 12 品詞に含めている。品詞では `ら` を区別できない。`彼ら` は 1 トークン(`名詞-代名詞-一般`)で、`ら` とは別。
- 再作成したインデックス(19,002 語)では、`ら` で終わる語は 45 語、そのうち連結語(末尾の形態素が `ら`)は 28 語(約 0.15%)。`研究者ら`、`担当者ら`、`県民ら`、`首脳ら`、`神谷浩史ら` など。`いくら`、`かしら`、`天ぷら` は 1 トークンで連結語ではない。
- `名詞-接尾` で終わる連結語は 1,517 語あり、大半は自然な語(`者` 118、`化` 46、`会` 38、`市` 31、`たち` 30、`等` 17 など)。

## 2. ユーザー判断

- 「末尾の `ら` が 1 トークンのときに取り除く」(トークン単位の完全一致。文字列の末尾一致ではない)。
- メインエージェントの提案で、「取り除く」ではなく「**区切り**」にする(`大統領 ら 民主党 幹部` のように `ら` が語の途中にあるケースを `民主党幹部` として拾うため)。ユーザーが「この形で進めて」と承認。

## 3. 仕様

新しい設定(System プロパティ。`DefaultContentsParser` の生成時に 1 回だけ読むため、変更には Fess の再起動が必要)

| プロパティ | 既定 | 意味 |
| --- | --- | --- |
| `fess.suggest.compound.break.tokens` | `ら` | 区切りにするトークンの表層の一覧(半角カンマ区切り)。未設定=既定の `ら`。設定済みで空文字=なし。それ以外=カンマで分割し、各要素の前後の空白(全角スペース含む)を除去、空要素は無視。指定した要素のみが有効(既定とマージしない)。要素にカンマは含められない。全角カンマ `、` `，` は区切りにならない(`ら、たち` は 1 つの要素 `ら、たち` になり、どのトークンにも一致しない。エラーも警告も出ない)。 |

挙動
- 区切りトークン = 表層(`getTerm()`)が一覧のいずれかと**完全一致**するトークン(部分一致・前方一致・末尾一致ではない。大文字小文字は区別。`getTerm()` の値そのままで照合)。0013 の区切り文字(括弧)と同じく、どの run にも入れず、そこで run を打ち切る(`isBreakToken` に統合。品詞が対象のトークンにだけ判定する短絡評価は維持)。前後の run は独立に評価される(0011 のトリム、2 トークン以上、`max.tokens`、`contains`、`max.length` は run ごと)。縮退カウンタ・ログは増やさない。
- 例(既定): `研究` `者` `ら` → `研究者`。`神谷` `浩史` `ら` → `神谷浩史`。`大統領` `ら` `民主党` `幹部` → `民主党幹部`(`大統領` は 1 トークンなので連結語にならない)。`米` `民主党` `幹部` `ら` → `米民主党幹部`。`日本` `ら`、`ちゃ` `ら` → 連結語なし。`人` `いくら` → `人いくら`(`いくら` は `ら` と一致しない)。`彼ら` は 1 トークンで影響なし。
- 運用で調整するには、このプロパティを変えて Fess を再起動し、サジェストを再生成する。例: `たち` と `等` も区切りにするなら `ら,たち,等`(既定とマージされないので `ら` も書く)。

## 7. 設計書・0009・0011・0013 との差異への追記

- 連結語を区切るトークンと設定 `fess.suggest.compound.break.tokens`(既定 `ら`。設計書に無い)。0013 の区切り文字と同じく、どの run にも入らず run を打ち切る。0009 の設定表への追加項目として、本書 3 章の表を参照する。
- 既知の限界: `ら` で終わる固有名詞が tokenizer で `X`+`ら` に分かれる場合は、連結語を失う。`たち`、`等` は既定では区切りにならない(運用で足す)。
