# 0016 連結対象品詞に `名詞-形容動詞語幹` を追加

実施: メインエージェント(原因・影響の調査、実装、記録)。ユーザー指示「連結対象に加えよう。コミットするのはちょっと待って、こちらで動作確認してから」による。プランの変更ではなく、軽微な追加対応(`task-workflow.md`「途中の追加指示」)。当初はコミットせず、ユーザーの実環境確認を待った。

## 1. 背景

ユーザーの問い: 形容動詞語幹を除外した理由はあるか。
- 設計書(連結対象品詞、対象外の一覧)に「形容動詞語幹」が対象外とあるだけで、理由の記載はない(数・助数詞とは違い、`#6` を悪化させない等の根拠が無い)。0003 の選択肢表、0006・0007(非対象品詞のテスト)にも議論の記録はない。保守的に外した可能性が高い。
- 実環境(`contents_analyzer_ja`)の解析: `健康`・`安全`・`特別`・`重要`・`平和`・`簡単` はいずれも `名詞-形容動詞語幹`。除外すると `健康診断`、`安全対策`、`特別養護老人ホーム` が連結語にならない。

## 2. 影響の測定(近似)

実環境の 100 文書(`fess.20261109121845553`)を 1000 文字ずつ `_analyze` して、Python で連結ロジックを再現し、対象に加えた場合と加えない場合を比較(0011 のトリム、0013 の括弧、0014 の `ら` の区切りは反映。チャンク分割は実装と同じでない近似)。

| | 連結語の種類数 |
| --- | --- |
| 除外(従来) | 9,525 |
| 加える | 9,829 |

- 新規 379 語(約 4%)。従来の 75 語は、より長い連結語に置き換わる(`事態宣言` → `緊急事態宣言`、`防衛監察` → `特別防衛監察`)。
- 良い例: `緊急事態宣言`、`名誉毀損`、`地球温暖化`、`安全保障環境`、`平和主義`、`可能性`、`公式アカウント`、`正式名称`、`主要都市`。
- ノイズの例: `正直自分`、`さまざま意見`、`めちゃくちゃビックリ`、`前提当たり前`、`圧倒的天才`、`少食アピール`(無作為 60 語中、明らかなノイズは 8 語前後=約 13%)。副詞的な語に偏る。必要なら `fess.suggest.compound.break.tokens` に足して区切る運用で調整する。

## 5. 同じ確認で分かったこと(0014 の実環境確認)

再生成されたインデックス(`fess.suggest.20261115060210050`、18,776 語)で確認: 末尾が `ら` の語は 20 語で、すべて単語としての `ら`(`まくら`、`天ぷら`、`いくら`、`人いくら` など)。`研究者ら`、`神谷浩史ら` は消え、`研究者`、`民主党幹部`、`神谷浩史`、`新型コロナ`、`高市早苗`、`togetter.com` が残る。括弧と文字を含む語は `（株）` の 1 語。0014 の区切りは実環境で効いている。

## 6. 設計書との差異

連結対象品詞は 13 種(設計書の 12 種に `名詞-形容動詞語幹` を追加)。設計書の「対象外: 形容動詞語幹」とは異なる。
