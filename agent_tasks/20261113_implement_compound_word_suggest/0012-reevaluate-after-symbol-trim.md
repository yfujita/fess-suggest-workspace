# 0012 記号トリム後の実環境の再評価

実施: メインエージェント。ユーザーが 0011 の jar(記号トリム入り)を Fess に組み込み、サジェストを再作成した(`fess.suggest.20261114113533081`、11:35〜11:40 生成)。評価方法は 0011 の 1 章と同じ(`fess.suggest` の全語を取得し、候補を単独で再解析して連結語(複数形態素)と断片に分類。分類は近似)。コード・テストの変更なし。

## 結果(前回 → 今回)

| 指標 | 前回 | 今回 |
| --- | --- | --- |
| 候補総数 | 18,550 | 18,230 |
| 連結語(複数形態素の語) | 5,561 | 5,176 |
| 記号を含む連結語 | 924(16.6%) | 439(8.5%) |
| 両端が記号の連結語 | 571 | **0** |

- 修正の意図どおり、両端に記号を持つ連結語は 0 件になった。`place-`、`dojo.`、`reserved.`、`(@...)`、`inc.)` 型は出ていない。`togetter.com` は残っている(`togetter` の候補に `togetter`、`togetter.com`、`togetter編集部`)。
- 例語は引き続き取れる: `新型`→`新型コロナウイルス`/`新型コロナ`/`新型コロナ禍`/`新型コロナ感染`、`大統領`→`大統領選`、`高市`→`高市早苗`/`高市首相`/`高市政権` ほか、`石破`→`石破茂`/`石破政権`/`石破内閣`、`ワクチン`→`ワクチン接種`、`神奈川`→`神奈川県`/`神奈川県川崎市`、`円安`。
- 注意: 前回と今回で候補の入れ替わりが大きい(前回のみ 3,863 語、今回のみ 3,543 語)。コーパス(クロール結果)が変わった可能性があり、総数の差は修正の効果とは言い切れない。比率(記号を含む割合、両端が記号の語)の比較は有効。

## 残っているノイズ

1. **内部に記号を含む連結語 439 語**(うち ASCII のみで `.` `-` `_` を含む語・ID・ドメインが 256 語)。仕様どおり(ユーザー判断「内部は残す」)。
2. **括弧・区切り記号などで日本語や文が連結された語 約 100 語**: `公表(出典`、`紫藤春香(はる`、`watch[sponsored`、`作者:柳田`、`益造,高橋`、`https://agencia.f`、`チップス」=英北部スコットランド`、`先端技術展－」（会期` など。記号が語の中にあるため trim では取れない。
3. **記号だけの候補が 202 語**(`.`、`/`、`://`、`-`、`@`、`|` など)。連結語ではなく、従来からある 1 トークンごとの断片の経路で出る(前回 212 語。今回の変更の対象外)。
4. 語尾の `ら`(`神谷浩史ら`、`大統領ら民主党幹部`)、サイトの定型文(`新着エントリー` など)は未対応(0011 の 8 章)。

## 判断が必要な点(ユーザーへ提示)

- 2 の対策案: 内部に残す記号を `.` `-` `_` などに限り、括弧・`:`・`,`・`/`・`&`・`@` などの前後で連結を切る。`togetter.com`、`aws-emulator` は残り、`公表(出典`、`作者:柳田` は連結語にならない。`zenn.dev/karamage` や `jpcert/cc` のような `/` を含む語は消える。
- 3 の対策案: 記号だけの候補(断片経路)を作らない。連結語とは別の改修になる。
- 4 の対策案: 語尾の接尾(`ら` など)を連結語の末尾から取り除く。
