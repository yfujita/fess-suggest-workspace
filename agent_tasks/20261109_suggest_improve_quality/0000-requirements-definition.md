# タスク: suggest_improve_quality

## 背景・目的

サジェストの品質を改善したいプロジェクトの一部。

## 要件

`agent_docs/global/improvement_points/20261109/suggest_quality_evaluation.md` の #2 複合語・固有名詞が候補にならない（高） を改善する。

たとえば、隣接する名詞を結合して、本文中に結合した名詞が存在するならば１単語として扱うようなことが案の１つ。
修正はなるべくfess-suggestの中で完結させたい。


## 対応範囲

- 改善の実施
